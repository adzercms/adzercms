# Security policy

## Supported versions

Fixes go to the latest release line. Until the first release, the supported version is the `main` branch.

## Reporting a vulnerability

Report it privately through [GitHub private vulnerability reporting](https://github.com/adzercms/adzercms/security/advisories/new) of the monorepository. Do not open a public issue, pull request or discussion about it. The package repositories `adzercms/<name>` are copies of the monorepository: report their vulnerabilities there too.

Include the affected package and version or commit, the steps to reproduce and the impact.

We confirm the report, agree with you on the fix and the disclosure date, fix the vulnerability in the monorepository and publish a GitHub security advisory with the fixed version. The advisory credits the reporter unless they ask otherwise.

Vulnerabilities of modules by other authors go to their authors.
