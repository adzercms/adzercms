# Security policy

## Supported versions

Fixes go to the latest release line. Until the first release, the supported version is the `main` branch.

## Reporting a vulnerability

Please report it privately through [GitHub private vulnerability reporting](https://github.com/adzercms/adzercms/security/advisories/new) in the monorepository. Don't open a public issue, pull request or discussion about it. The package repositories `adzercms/<name>` are copies of the monorepository, so report their vulnerabilities there too.

Tell us which package and version or commit is affected, how to reproduce the problem and what an attacker can do with it.

We'll confirm we got your report, agree with you on the fix and the disclosure date, fix the vulnerability in the monorepository and publish a GitHub security advisory with the fixed version. The advisory credits you as the reporter unless you'd rather stay anonymous.

Vulnerabilities in modules by other authors should be reported to those authors.
