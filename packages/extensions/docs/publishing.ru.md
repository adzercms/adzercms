# Размещение расширения

[Каталог расширений AdzerCMS](https://adzercms.com/extensions) собирает модули, интеграции, темы, шаблоны сайтов и мини-приложения любых авторов. Каждый сайт на AdzerCMS показывает его в разделе «Расширения» админки и ставит расширения из него через Composer.

## Подготовьте пакет

Расширение — это пакет Composer типа `adzercms-module` в публичном git-репозитории. Заведите его из шаблона модуля и опишите в `composer.json`, как показано в разделе [Свой модуль](https://github.com/adzercms/adzercms/blob/main/docs/module-development.ru.md#пакет).

Всё остальное карточка каталога берёт из пакета: описание на языке читателя, категории, версию, ссылку `homepage` и репозиторий с кодом. Версия — последняя стабильная, а пока стабильной нет — ветка по умолчанию.

## Проверьте его

CI шаблона запускает [проверку модуля](https://github.com/adzercms/adzercms/blob/main/docs/module-development.ru.md#проверка-модуля) на каждый push. Исправьте всё, что она отклоняет, до публикации: движок прогоняет ту же проверку на каждой опубликованной версии, а сайты перед установкой версии без отметки «проверен» просят подтверждения.

## Опубликуйте его на Packagist

1. Добавьте репозиторий на [packagist.org](https://packagist.org/packages/submit) под именем пакета из `composer.json`.
2. Настройте обновление Packagist по каждому push: [как обновлять пакеты](https://packagist.org/about#how-to-update-packages).
3. Выпустите версию git-тегом вида `1.0.0` и отправьте тег. Поле `version` в `composer.json` не указывайте: Composer берёт версию из тега.

## Добавьте ключ автора

Каталог принимает только пакет с ключом автора того, кто его подаёт.

1. Войдите на [adzercms.com](https://adzercms.com) и откройте [Мои расширения](https://adzercms.com/extensions/mine). Там ваш ключ — готовой строкой для `composer.json`.
2. Добавьте ключ в `extra.adzercms` рядом с бандлом и описанием:

   ```json
   "extra": {
       "adzercms": {
           "bundle": "Acme\\Pigeon\\PigeonBundle",
           "description": {"ru": "SMS голубиной почтой"},
           "author": "<ваш ключ>"
       }
   }
   ```

3. Выпустите новую версию с ключом.

Если в следующей версии ключа не будет, запись уйдёт из каталога.

## Заведите запись

В «Моих расширениях» нажмите «+ Расширение» и укажите имя пакета, тип и, если есть, адрес демо-сайта. Остальное приходит из пакета: каталог обновляет его раз в сутки и при каждом сохранении записи.

Новая запись ждёт решения оператора каталога. О публикации или отказе придёт оповещение, отказ — с причиной, её же «Мои расширения» показывают рядом с записью.

- Правка опубликованной записи видна сразу
- Сохранение отклонённой или снятой записи снова отправляет её на решение

## Выпускайте новые версии

Отметьте тегом и отправьте новую версию. Каталог покажет её после ближайшего обновления.
