# Модули

[English](modules.md) | Русский

Модуль — пакет Composer типа `adzercms-module` с бандлом Symfony. Модули функций добавляют приложению функции. Модули родов реализуют сменную часть: админку, кабинет, тему, вход через сервис, шлюз сообщений на телефон, бота мессенджера, проверку «не робот».

## Выбрать модуль

Установите пакет и добавьте его ключ в ключ окружения его рода в `.env.local`:

```sh
composer require acme/shop acme/pigeon
```

```dotenv
MODULES=Shop
SMS_MODULES=Pigeon
```

Ключ модуля — имя класса бандла без `Bundle`: у `ShopBundle` ключ `Shop`.

| Ключ | Род | Модулей |
|---|---|---|
| `MODULES` | модули функций | список |
| `ADMIN_MODULE` | админка | один |
| `CABINET_MODULE` | кабинет | один |
| `THEME_MODULE` | тема | один |
| `LOGIN_MODULES` | вход через сервис | список |
| `SMS_MODULES` | шлюз сообщений на телефон | список |
| `BOT_MODULES` | бот мессенджера | список |
| `CAPTCHA_MODULES` | проверка «не робот» | список |

Список — через запятую. Модули функций объявляют свои роды со своими ключами.

Затем накатите схему выбора:

```sh
bin/console doctrine:migrations:migrate
```

Установленный, но не выбранный модуль ничего не добавляет: ни сервисов, ни маршрутов, ни команд, ни таблиц. Сборка останавливается на неизвестном ключе и на модуле, чей обязательный модуль не выбран; сообщение перечисляет доступные ключи.

## Включить модуль рода

Модуль рода со списком работает, когда включён его переключатель и заданы обязательные данные доступа. Ключи настроек — `<род>.<модуль>.<поле>`:

```sh
bin/console adzercms:setting
bin/console adzercms:setting sms.pigeon.enabled 1
printf '%s' "$PIGEON_TOKEN" | bin/console adzercms:setting sms.pigeon.token --stdin
```

Первая команда перечисляет все настройки с ключами. Секреты принимаются только из stdin. Выключенный модуль сохраняет данные доступа.

Шлюз сообщений и проверка «не робот» берут первый включённый модуль в порядке выбора. Входы через сервисы и боты работают все включённые.

## Модуль одного экземпляра

Держите его каталогом в `modules/`: шаблон проекта подключает `modules/*` path-репозиторием, `composer require` берёт модуль по имени пакета.
